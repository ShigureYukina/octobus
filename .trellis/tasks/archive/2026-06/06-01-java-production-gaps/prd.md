# Java 生产就绪补齐

## Goal

补齐 Java 版 Octobus 在管理前端对接、MySQL 数据库、Gemini 提供者和全表备份恢复四个缺口，使其达到**有条件投产**的水平（缺管理前端时可通过 API 管理，全功能替代 Go 版本需同时解决四个缺口）。

## Requirements

### 范围边界

- 本任务为**父任务**，不直接包含实现工作。四个子任务各有独立交付物。
- 四个子任务之间无硬性依赖，可独立规划、实现、验证。

### 跨子任务约束

- **API 兼容性**：所有子任务的变更不得破坏已有 35+ 管理端点的 Go 兼容响应格式（`{code, message, data}`）。
- **Spring Boot 3.3 / WebFlux**：所有实现必须沿用现有响应式栈，不得引入阻塞 JDBC（MySQL 通过 R2DBC 或响应式驱动接入）。
- **配置外部化**：新功能（MySQL 连接、前端静态资源路径等）必须可通过 `application.yml` 和环境变量覆盖。
- **回滚原则**：每个子任务的变更应独立可回滚，确保不影响其他模块。

## Acceptance Criteria

- [ ] 四个子任务全部完成，各自满足其 PRD 中的验收条件
- [ ] 全量管理 API 测试（35+ 端点）在四个变更叠加后仍全部通过
- [ ] 所有可配置项有对应的环境变量命名（前缀 `OCTOBUS_`）

## Notes

- 本任务不涉及 Go 版本的改动
- Java 版本仍在 `java/` 目录下，Git 分支 `feat/java-m1-bootstrap`
- 父任务负责最终集成验证，各子任务独立完成开发和单体测试
